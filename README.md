# x1080x-ex

**让浏览、搜索、保存资源更方便的 Tampermonkey 浏览器脚本。**

在支持的网站上增加一键下载、复制番号、跨站搜索、批量打开、浏览进度定位和预览大图等实用功能。安装后直接在网页上操作，常用功能都可以在设置里开启或关闭。

> 这是独立的浏览器增强脚本，并非相关网站的官方产品。请遵守各网站规则，仅下载和使用自己有权限访问的内容；脚本不绕过登录、付费或验证码。

## 🚀 3 步安装

1. 在 Chrome、Edge 或 Firefox 中安装 [Tampermonkey（油猴）](https://www.tampermonkey.net/)。
2. 点击 **[安装 x1080x-ex 正式版](https://raw.githubusercontent.com/Kesuy/x1080x-ex/main/dist/x1080x-ex.user.js)**，在 Tampermonkey 弹出的页面中确认安装。
3. 打开下方支持的网站并刷新页面，就可以使用脚本提供的按钮。

**已有旧版或 Beta？** 直接点击同一个安装地址覆盖更新即可。原来的脚本设置和已保存的浏览记录会继续保留。也可前往 [GitHub Releases 下载正式版本](https://github.com/Kesuy/x1080x-ex/releases)。

## ✨ 最常用的功能

### 1. 一键下载与 Preview

在帖子或文章详情页，看到下载按钮 <kbd>↓</kbd> 时，点击即可处理当前页面支持的图片、Preview 或附件。

- 下载文件尽量按**番号和标题**整理命名，减少手工重命名。
- 在 x1080x 页面，脚本可按番号查找 JavClub Preview；不可用时可尝试 JavFree 等后备来源。
- 在 JavClub 文章中，Preview 缩略图可展开为大图。新版的「関連作品」（相关作品）推荐区会保持原样，不会被当作 Preview 放大或下载。
- 下载进行中可能显示数量或状态；实际是否保存成功，以浏览器下载列表为准。

**注意：** 网站原有的附件权限、下载额度、付费确认和人机验证依然有效。没有权限的文件不能通过脚本直接取得。

### 2. 快速搜索、复制番号

在有相应按钮的页面中：

- <kbd>🔍</kbd> **搜索**：把当前番号带到另一个支持的网站搜索。
- <kbd>📋</kbd> **复制**：一键复制当前番号。
- 对 FC2 作品，跨站搜索会优先使用**纯数字部分**，提高匹配率。

### 3. 批量打开帖子

打开 x1080x 或 JavClub 的列表页，找到批量打开工具栏：

- **叠页图标 + 数字**：点击后按列表顺序在后台打开多个主题；运行中再次点击可停止后续操作。
- **▾ 下拉菜单**：切换并立即执行「仅打开未浏览」或「打开本页全部」，脚本会记住你的选择。
- **准星图标**：根据脚本保存的历史记录寻找上次浏览到的位置，帮助继续往下看。

在 **JavClub** 上，这组按钮位于顶部灰色导航栏右侧，顺序是 **批量打开 → 定位浏览进度**。

批量打开时，标签页会提示正在运行；关闭或刷新可能出现浏览器确认。如果新标签触发 Cloudflare 验证，脚本会尽可能停止后续批量打开并提醒你**手动完成验证**，不会代替你通过验证。

### 4. 已浏览标记、历史记录和过滤

开启「保存批量打开记录」后，已记录的主题会用颜色标记，默认是**紫色 `#bd10e0`**，可以自定义或恢复默认。配合「仅打开未浏览」和准星定位按钮，不用每次从第一页重新找。

还可以在设置中输入不想看到的关键词，减少不感兴趣的列表内容。

> 「定位浏览进度」依据的是**脚本自身保存的记录**，无法直接读取浏览器原生的全部浏览历史。更换浏览器或清除脚本存储后，未导出的旧记录不保证自动恢复。

### 5. 98堂浮动助手

在支持的帖子页面右侧显示可拖动的助手：

- 列出**楼主附件**，点击定位图标跳到对应附件，点击下载图标调用网站原有下载方式。
- 显示「回复后可见」提示，但不会自动获取隐藏内容。
- 需要回复时，可使用快捷回复按钮；回复内容能在设置中修改。已有草稿不会被自动覆盖。
- 拖动助手顶部即可移动位置，脚本会记住它；也可以在设置中重置。

## ⚙️ 设置在哪里？

打开支持的网站，点击浏览器工具栏中的 **Tampermonkey 图标 → x1080x-ex 的菜单**，选择需要的设置：

| 设置入口 | 主要选项 |
| --- | --- |
| ⚙️ x1080x 设置 | 下载、预览、搜索与复制、批量打开、浏览记录、关键词过滤 |
| ⚙️ JavClub 设置 | 文章宽度、Preview 大图、下载按钮、批量打开、历史颜色、关键词过滤 |
| ⚙️ JavFree 设置 | 搜索、复制番号和 Preview 下载 |
| ⚙️ 98堂设置 | 附件图标、快捷回复、回复短语、浮动栏位置 |
| ⚙️ FC2CMADB：番号搜索 JavClub | 是否启用点击番号搜索 |

大部分选项可以独立开启或关闭。修改后请点击**保存**；如页面没有立即更新，刷新网页即可。

### 推荐给新用户的设置

建议保留「下载增强」「跨站搜索」「复制番号」等默认设置。经常使用批量打开时，可开启**保存批量打开记录**，再选择**仅打开未浏览**，并保持**定位浏览进度**开启。

## ❓ 常见问题

<details>
<summary><strong>安装后没有看到按钮？</strong></summary>

检查 Tampermonkey 是否已启用脚本、当前网站是否受支持、对应功能是否在设置中开启，然后刷新页面。下载和复制按钮通常在详情页，批量打开按钮通常在列表页，不是每个页面都会显示全部按钮。
</details>

<details>
<summary><strong>为什么图片或附件没有下载成功？</strong></summary>

先检查浏览器下载权限、网站登录状态、文件是否仍有效，以及网站是否要求先进行授权或验证。有时 Preview 来源不可用，可以尝试在设置中开启后备源。完成提示不一定代表文件已实际保存，请查看浏览器下载记录。
</details>

<details>
<summary><strong>为什么已经看过的帖子没有标紫色？</strong></summary>

请确认已经开启「保存批量打开记录」。脚本无法自动读取 Chrome 所有原生访问历史；历史标记依赖脚本已保存的数据和可匹配的帖子信息。更换网站域名时通常仍可沿用原设置，但帖子编号或标题同时变更时可能无法全部匹配。
</details>

<details>
<summary><strong>换了域名，还能继续使用吗？</strong></summary>

JavClub 已使用 `javclub.me`，原 `hdblog.me` 保留兼容。x1080x 默认域名为 `1080xin.com`；如将来再改域名，可以从 Tampermonkey 菜单选择「🌐 设置 x1080x 站点域名」，输入新的地址并刷新页面。
</details>

<details>
<summary><strong>如何更新？会清空设置吗？</strong></summary>

点击上方「安装 x1080x-ex 正式版」即可覆盖安装；版本更新通常不会清空原有设置及脚本浏览记录。不要在未备份的情况下删除脚本数据或重置脚本存储。
</details>

<details>
<summary><strong>旧论坛历史记录怎么迁移？</strong></summary>

Tampermonkey 菜单提供「检查旧版浏览记录」「迁移旧版 x1080x 浏览记录到新版」等入口。少数无法匹配的旧帖子可能需要人工恢复。详细步骤见[历史记录与技术说明存档](docs/README-technical-archive.md#从本机-chrome-访问历史恢复旧-tid)。
</details>

遇到问题可前往 [GitHub Issues 反馈](https://github.com/Kesuy/x1080x-ex/issues)，建议附上**网站地址、页面链接、脚本版本、问题截图及操作步骤**。请勿公开账号、Cookie 或其他敏感信息。
