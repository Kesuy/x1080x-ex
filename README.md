# x1080x-ex

面向 `1080xin.com`（兼容原 `agaghhh.cc`）/ `hdblog.me` 的 Tampermonkey 增强脚本。

## 主要功能

- **一键下载**：旧版 Discuz 下载主楼附件、图片、Preview 大图，并将磁力链转换为 `.torrent`；新版 `/resources/` 详情页支持正文图片和 Preview 下载。新版附件由网站自身的授权/计次按钮下载，脚本不绕过权限或代替原生按钮。
- **下载保护**：下载进行中在浏览器标签标题显示“⬇ 下载中”，关闭标签页时弹出浏览器确认提示，完成后自动恢复。
- **自动命名**：自动识别番号、清理标题并处理 Windows 非法字符，支持 FC2、1PON、CARIB 等规则。
- **Preview 大图**：agaghhh 按番号优先从 hdblog 获取 Preview；FC2 会自动只用纯数字部分联动（如 `FC2-4906444` → `4906444`）；hdblog 无结果或 Preview 失效时可回退到 JavFree，再回退 FANZA / MGStage 官方源。HDblog 文章页自身无可用 Preview 时也可从 JavFree 补图。
- **Pixhost 解析**：自动解析 Preview 原图，并对 `pixhost.to` / `pixhost.cc` 等同一资源进行去重；同一文章同时有普通版和 4K Preview 时优先普通版，仅在普通版不可用时回退 4K。
- **跨站搜索**：agaghhh 与 hdblog 标题旁提供 `🔍`，可按番号直接搜索另一站；FC2 标题会去掉 `FC2 / PPV` 前缀，仅搜索数字番号。
- **复制番号**：agaghhh 与 hdblog 标题旁提供 `📋`，一键把当前番号复制到剪切板。
- **FC2CMADB 搜索 HDBLOG**：在 FC2CMADB 作品列表（例如演员页面）点击封面左上角纯数字番号，直接以该号码在 HDBLOG 搜索并在新标签页打开；封面原链接保留不变，兼容动态分页。
- **真实演员查询**：主楼演员信息为空时，可通过 av-wiki 查询并补充到下载文件名。
- **批量打开**：列表和搜索页支持顺序后台打开主题；执行期间标签标题显示“↗ 批量打开中”，关闭或刷新页面会由浏览器确认，完成/停止后自动解除。
- **搜索增强**：支持关键词过滤、搜索结果仅 1 个主题时自动跳转。
- **qBittorrent 回退**：公共 torrent 缓存失败时，可通过 qBittorrent 5.2+ 获取 metadata 并导出 `.torrent`。

### BT 图片命名

```text
1 张：SVMGM-050.jpg
2 张：SVMGM-050 A.jpg / SVMGM-050 B.jpg
3 张：SVMGM-050 A.jpg / SVMGM-050 B.jpg / SVMGM-050 C.jpg
```

超过 26 张继续使用 `AA`、`AB`……。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 点击 **[安装 x1080x-ex](https://raw.githubusercontent.com/Kesuy/x1080x-ex/main/dist/x1080x-ex.user.js)**
3. 打开支持的网站并刷新页面

正式版本也会发布到 [GitHub Releases](https://github.com/Kesuy/x1080x-ex/releases)。

## 设置

设置窗口已统一为分类导航布局：桌面端左侧分类、右侧配置，窄屏自动调整为顶部横向分类。仅显示当前类别，底部始终保留 **取消 / 保存**；切换类别不会丢失尚未保存的修改。

- **x1080x**：批量打开、浏览记录、搜索与过滤、下载与按钮、预览与演员；qBittorrent 回退设置独立成类。
- **HDBLOG**：文章布局、下载与按钮、预览与修复、批量打开、浏览记录、关键词过滤；额外图床域名独立成类。
- **JavFree**：搜索功能、文章操作。
- **FC2CMADB**：只有一项开关，仍保留简洁的 Tampermonkey 菜单设置。

原有配置键、保存行为、默认值及开关依赖均保持不变；例如关闭批量打开后，其间隔和历史相关选项仍按原有规则禁用。


### x1080x（1080xin.com / agaghhh.cc）

已适配改版后的 `/boards/<ID>` 列表和 `/resources/<ID>` 详情页面：列表可批量后台打开、跳过已打开主题、持久标紫色并定位跨页浏览进度；详情页可识别 FC2 番号、复制、搜索 HDblog、嵌入 Preview，以及下载正文图片。新版原生附件使用按钮而不是直接下载 URL，脚本的蓝色下载按钮只处理可直接获取的图片及 Preview，附件仍需在网站内点击下载。

**备注**：改版后的 `/search` 结果结构未提供样本，旧 Discuz 搜索页的关键词屏蔽/单结果自动跳转逻辑暂未覆盖新版搜索页。

通过 **⚙️ x1080x 设置** 可独立控制：

- 下载增强
- 下载时保护标签页（默认开启）
- Preview 大图
- JavFree Preview 后备源（默认开启，hdblog 无可用 Preview 时启用）
- 官方 Preview 后备源（在 hdblog / JavFree 都不可用时启用）
- 跨站搜索
- 复制番号按钮（默认开启）
- 搜索结果屏蔽（默认开启；关键词匹配标题、摘要或所属版块，默认屏蔽“无码破解 / 無碼破解”，支持换行、逗号或分号自定义）
- 搜索单结果自动跳转
- 批量打开帖子（默认随机间隔 1.8–3.5 秒，可自定义并恢复默认）
- 保存批量打开记录（可设置最多保存 1–50000 条；命中的主题在列表页按自定义颜色标记，默认 `#bd10e0`，可一键还原默认紫色；超过上限自动淘汰最旧记录）
- 批量只打开未打开主题（默认关闭；依赖“保存批量打开记录”，开启后批量打开会跳过已有记录的主题）
- 定位浏览进度（默认开启；依赖“保存批量打开记录”，点击后从列表第一页向后实际读取各分页，定位“已打开/未打开”混合页或相邻分页边界；扫描时显示进度，再次点击可停止，单次最多检查 120 页；**仅识别脚本持久保存的批量打开记录，不读取 Chrome 自身的 :visited 历史**）
- 真实演员查询
- qBittorrent metadata 回退

### hdblog.me

通过 **⚙️ hdblog 设置** 可控制：

- 文章宽度
- Preview 大图展开
- JavFree Preview 后备源（默认开启；当前文章无可用 Preview 时按番号补第 2 张 Preview）
- 已删除文章自动搜索 JavFree（默认开启；打开 HDblog 404 历史文章时新开 JavFree 搜索页）
- 图片下载按钮
- 下载时标记标签页并在关闭时提醒（默认开启）
- 跨站搜索
- 复制番号按钮（默认开启）
- 搜索结果过滤与自动跳转
- 正常浏览关键词屏蔽（默认关闭；首页、分类、标签、分页等文章列表共用搜索屏蔽关键词，不影响文章详情页）
- 批量打开主题（默认随机间隔 0.8–1.6 秒，可自定义并恢复默认）
- 保存批量打开记录（可设置最多保存 1–50000 条；已记录文章持久标记，手动访问过的链接也使用同一颜色；默认 `#bd10e0`，可自定义并还原默认紫色）
- 只打开未打开的主题（默认关闭；依赖“保存批量打开记录”，开启后批量打开会跳过已有记录的文章）
- 定位浏览进度（默认开启；依赖“保存批量打开记录”，点击后从列表第一页跨页检索，跳到实际查出的已打开/未打开主题交界页，不再仅靠上次批量打开所在页；**浏览器原生 :visited 历史无法读取**，最多扫描 120 页）
- 额外图床域名

### fc2cmadb.com

通过 Tampermonkey 菜单 **⚙️ FC2CMADB：番号搜索 HDBLOG** 独立开启或关闭此功能（默认开启，切换后刷新页面生效）。

### javfree.me

通过 **⚙️ JavFree 设置** 可独立控制：

- 搜索单结果自动跳转（默认开启）
- x1080x 搜索按钮（默认开启；详情页识别当前番号后直接搜索 x1080x 站点）
- 复制番号按钮（默认开启；详情页标题旁显示 📋，行为与 HDblog 一致）
- Preview 下载按钮（默认开启；详情页只下载封面后的第 1 张 Preview，并按番号保存，例如 `SAN-437.jpg`）

## 域名

默认支持：

- `1080xin.com`（x1080x 当前默认域名）
- `agaghhh.cc`（原域名，保留兼容）
- `hdblog.me`
- `javfree.me`
- `fc2cmadb.com`

Tampermonkey 菜单中的 **🌐 设置 x1080x 站点域名** 用于修改当前站点地址，默认 `1080xin.com`。保存后，跨站搜索及浏览进度会使用该地址；旧域名仍可识别，原有历史记录不受影响。**设置匹配域名 / 添加当前域名 / 重置默认域名** 继续保留。

**历史记录兼容**：新旧域名共用原有 Tampermonkey `x1080x-ex:agaghhh-batch-open-history` 存储键，不会清空数据。旧 Discuz 帖子采用 `tid:<数字>`，新站 `/resources/` 帖子采用 `resource:<ID>`，不同 ID 不能自动换算；新版板块使用自己的分页范围，旧版进度记录仍会保留。启用保存批量打开记录后，手动访问和批量打开的新主题均会记录。Chrome 原生 `:visited` 历史无法从 Tampermonkey 跨域读取，升级前未保存到脚本中的手动访问不能自动补录。
