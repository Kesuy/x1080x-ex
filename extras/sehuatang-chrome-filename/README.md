# 98堂 Chrome 原生下载自动命名扩展（可选）

本扩展专门解决 **Chrome 按服务器 `Content-Disposition` 原文件名保存 TXT** 的问题。网站对额外 `fetch()`、`GM_xmlhttpRequest` 请求可能返回 HTTP 403，因此本扩展 **不请求或下载附件内容**，也不会更改站点权限。

## 如何安装

1. 从本项目正式版 Release 下载 `sehuatang-filename-chrome.zip`，解压到长期保留的文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions/`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的文件夹。
4. 使用最新版 x1080x-ex 油猴脚本，刷新已经打开的 98堂帖子，再点击浮动栏的下载按钮。

扩展会读取帖子标题和楼主的 TXT 附件名称，在下载前注册建议文件名；浏览器进行**原始网站下载**时，在 Chrome 确定文件名的阶段应用新名称。如果文件名被占用，会由 Chrome 按规则加序号。目录、清单等 TXT 不重命名。

- 无扩展：油猴脚本仍直接使用网站原生下载，不会因重命名触发 HTTP 403；可通过「复制建议文件名」手动重命名。
- 有扩展：下载仍使用网站原生请求，但 Chrome 可以使用帖子标题作为保存名。
- 网站登录、附件购买、积分、验证码和其他权限始终由网站控制。
- 修改或删除扩展后，如需更新请在 `chrome://extensions/` 重新加载并刷新帖子。
- 本扩展仅支持 Chromium/Chrome 桌面端的扩展 API，不支持直接装入 Tampermonkey。

本工具不会把帖子内容、Cookies 或下载链接发送到外部服务；只在本机浏览器会话中临时存储附件链接与建议文件名的关联。
